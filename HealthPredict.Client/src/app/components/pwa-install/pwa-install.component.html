📱 Para mejor experiencia
Agregue esta app a su pantalla de inicio para usar sin barra de URL
Instrucciones para iOS (iPhone/iPad)
  1. Toque el botón "Compartir" en Safari
  2. Seleccione "Agregar a pantalla de inicio"
  3. Confirme el nombre y toque "Agregar"
  4. Abra la app desde el ícono en su pantalla de inicio
La app se abrirá en pantalla completa sin barra de URL
